# Theme and Visual Direction

## Dark mode
- deep atmospheric background
- rune cards with layered surfaces
- high-contrast pale text
- teal/slate accent

## Light mode
- parchment/stone inspired surfaces
- slate-blue accent
- darker text for readability

## Graphics direction
Create original:
- subtle rune constellations
- stone/metal texture overlays
- hero illustrations using geometric bind-rune motifs
- soft aurora-like gradients

Keep graphics lightweight and performance-safe.
